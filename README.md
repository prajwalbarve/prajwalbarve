## Selected projects

### [VAPT Security Scanner](https://github.com/prajwalbarve/vapt-security-scanner)

**Python · HTTP/HTTPS · Web & API security · JSON reporting**

An independently developed Python scanner that checks for potential web and API security weaknesses, including selected exposed-file paths, response indicators, reflection behavior, and API authentication concerns.

- Built custom Python checks rather than relying on an external scanning engine.
- Explores practical challenges in automated vulnerability discovery.
- Focuses on separating **candidate findings** from issues confirmed through manual testing.
- **Status:** Work in progress. Detection coverage and validation need further improvement.

**[Explore the source code](https://github.com/prajwalbarve/vapt-security-scanner)**

### AI-Assisted SOC Platform

**Python · FastAPI · Splunk · Local LLMs · Linux**

An ongoing project exploring how security-event collection and local language models can assist with analyzing and prioritizing alerts.
